## 🌌 Sobre o Projeto

Meu portfólio pessoal, construído do zero com **HTML5**, **CSS3** e **JavaScript puro** (vanilla). O visual foi pensado em uma estética **dark "aeroespacial"** — azul-marinho profundo com detalhes em ciano — refletindo meu interesse pelo setor aeronáutico e aeroespacial.

O site apresenta minha trajetória, habilidades, projetos e formas de contato de forma responsiva e interativa.

## ✨ Funcionalidades

- 🎨 **Tema dark aeroespacial** — paleta azul-marinho + ciano com gradientes
- ⭐ **Campo de estrelas animado** em `canvas`
- ⌨️ **Efeito de digitação** (typewriter) no hero
- 📱 **Totalmente responsivo** — mobile-first, menu hambúrguer
- 🔍 **Animações ao rolar** com `IntersectionObserver`
- ♿ **Acessível** — respeita `prefers-reduced-motion`, navegação por âncoras, aria-labels
- 🖼️ **Fallback de avatar** por iniciais caso a foto não esteja presente

## 🗂️ Estrutura

```text
MariaEduardaBatt.github.io/
├── index.html          # Página principal (one-page)
├── css/
│   ├── styles.css      # Estilos e tema
│   └── animations.css  # Animações
├── js/
│   └── main.js         # Estrelas, typewriter, menu e scroll
├── assets/
│   └── images/
│       └── perfil.jpg  # Foto de perfil (adicione sua imagem aqui)

```

## 🚀 Como Executar Localmente

```bash
git clone https://github.com/MariaEduardaBatt/MariaEduardaBatt.github.io.git
cd MariaEduardaBatt.github.io

# Opção 1 — abrir direto
start index.html

# Opção 2 — servidor local (Python)
python -m http.server 8000
# acesse http://localhost:8000
```

## 🖼️ Foto de Perfil

Para exibir sua foto no hero, coloque uma imagem em **`assets/images/perfil.jpg`**
(JPG/PNG/WebP, boa resolução e centralizada). Sem a imagem, o site mostra um avatar com as iniciais **MD**.
