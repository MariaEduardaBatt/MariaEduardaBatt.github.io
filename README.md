## 🌌 Sobre o Projeto

Meu **portfólio pessoal**, construído do zero com **HTML5**, **CSS3** e **JavaScript puro** (sem frameworks). A identidade visual segue uma estética **dark "aeroespacial"** — azul-marinho profundo com detalhes em ciano — que reflete meu interesse pelo setor aeronáutico e aeroespacial.

O objetivo é apresentar, de forma clara e interativa, minha trajetória na Engenharia de Computação: **formação**, **experiências** (P&D, robótica industrial, full stack e liderança), **habilidades**, **projetos** e canais de **contato**.

## ✨ Funcionalidades

- 🎨 **Tema dark aeroespacial** — paleta azul-marinho + ciano com gradientes e "nebulosas"
- ⭐ **Campo de estrelas animado** — renderizado em `canvas`, com parallax sutil
- ⌨️ **Efeito de digitação** (typewriter) no hero
- 📱 **Totalmente responsivo** — mobile-first, com menu hambúrguer animado
- 🔍 **Animações ao rolar** com `IntersectionObserver` (revelação progressiva)
- 🧭 **Navegação com link ativo** conforme a seção visível
- ♿ **Acessível** — respeita `prefers-reduced-motion`, `aria-labels`, navegação por âncoras
- 🖼️ **Fallback de avatar** com as iniciais **MD** quando não há foto

## 🚀 Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/MariaEduardaBatt/MariaEduardaBatt.github.io.git
cd MariaEduardaBatt.github.io

# Opção 1 — abrir direto no navegador
start index.html

# Opção 2 — servidor local (Python)
python -m http.server 8000
# Acesse http://localhost:8000
```

> 💡 Nenhum `npm install` é necessário: o projeto é 100% estático.

## 🚢 Publicação no GitHub Pages

Este repositório segue o padrão de **user site** do GitHub Pages (`<usuário>.github.io`):

1. Faça `push` na branch `main`.
2. Acesse **Settings → Pages** do repositório.
3. Em **Source**, selecione `Deploy from a branch` → branch `main` → pasta `/ (root)`.
4. O site fica disponível em `https://mariaeduardabatt.github.io`.

## 🎨 Personalização

Todos os dados ficam em um único arquivo (`index.html`), fácil de editar:

- **Nome e textos** — seções `hero`, `sobre` e `contato`
- **Habilidades** — bloco de `chips` em cada categoria da seção `#habilidades`
- **Projetos** — cada `article.project-card` em `#projetos` (título, descrição, tags e link)
- **Experiências** — itens da linha do tempo em `#trajetoria`
- **Formação** — cards `.edu-card` em `#formacao`
- **Foto** — substitua `assets/images/perfil.jpg` (JPG/PNG/WebP, boa resolução e centralizada)
- **Cores** — variáveis CSS no topo de `css/styles.css` (`:root`)
